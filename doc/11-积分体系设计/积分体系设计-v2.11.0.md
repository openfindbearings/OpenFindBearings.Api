# 积分体系设计 v2.11.0（轴承币定名 + 游戏中心）

> 版本：v2.11.0 | 日期：2026-09-27 | 上一版：v2.10.0（商家金定名 + 默认金库支付 + 寻货需求置顶）
> 本版性质：命名与玩法增量版。

---

## 一、个人积分对外定名"轴承币"

- 与"商家金"对称定名：个人可花货币=**轴承币**，店铺金库货币=**商家金**，勋章 meta 分=**荣誉分**——三币三个名字，彻底消除"积分/成就点都带分字"的混淆。
- 改名范围：**纯展示层**（Taro 用户文案、规则页、文档），代码标识符/数据库列/API JSON 字段（points*）一律不动（同商家金做法）。
- Admin 运营后台保留"积分"内部术语（积分规则/发放流水），文档注明"对外=轴承币"。
- 逐处替换不做全局盲改：荣誉分/成就点语境不碰；挂礼收入、金库红线两处语义实为商家金，单独修正。

## 二、游戏中心（minigame 发放场景）

- 新发放类型 `PointTransaction.TypeMinigame = "minigame"`；规则种子（迁移 AddMinigame）：每局 5 分、日上限 10 分，Admin 规则页可调。
- 首款游戏=轴承连连看（题库=MinIO 爬图管线沉淀的有图轴承，类型打散防照片脸盲）。
- 架构=方案 A 进程内插件（`IGameProvider` + `/api/games/{key}/board|result` 统一端点 + BFF 通用代理 + Taro 注册表），微服务为既定演进路径但暂不拆——详见《游戏中心设计 v1.0.0》。
- 合规：娱乐分**不进商家金 trickle 白名单**（与登录签到同类排除，防农场刷金库）；低额+日限+gameId 幂等三件套防刷；原型期客户端信任制。
- 入口：我的页四宫格"游戏中心"（原"设置"位，设置保留 NavBar 右上角）。

## 三、金库收支明细与规则页（v2.10.0 同批落地补记）

- 金库流水从挂礼页拆出为独立"收支明细"页（pages/merchant/treasury）；gifts 页回归纯挂礼管理。
- 规则页 pages/rules/index（kind=points|gold 双内容）：轴承币明细右上角"轴承币规则"、金库侧"商家金规则"；底稿=《轴承币与商家金规则说明 v1.1.0》。
