## 二、未实现项分批规划（按实现难易度升序）

### 批次一：低难度·单点·快赢（无新实体或纯配置/顺带）

| 项 | 难度 | 改动面 |
|---|---|---|
| P2 注释订正 | 极低 | UserContextMiddleware L174 一处注释顺手改 |
| G2 每日任务板三件套（+30） | 低 | 新 grantType `daily_combo` + 规则行；完成态判定复用 tasks 端点既有逻辑（签到/纠错/应答当日完成判定），三项齐时服务端发 +30（bizId=业务日键幂等） |
| G7 用户积分等级 Lv1-10 | 低-中 | 阈值表（复用 PointGrantRule 同款配置化，或成就点式表）+ TotalEarned 档位查询 + 资料页/应答署名/纠错署名埋点；纯展示无特权 |

### 批次二：中难度·核心链路或单点引擎（需谨慎设计）

| 项 | 难度 | 改动面 |
|---|---|---|
| G1 积分暴击/双倍掉落 | 中 | 规则表加概率参数 + GrantAsync 判定链 RNG（10%/2% 概率）→ 金额覆写仍守日上限；前端暴击/传说动画 |
| G11 限量徽章机制 | 中 | AchievementDefinition 加 IsLimited/窗口字段 + 创站元老（前 100 注册）种子 + 注册序号截断判定；执行纪律=绝版永不返场 |
| 称号佩戴选择 | 中 | 用户可选佩戴一个称号（资料页/署名读取佩戴字段）；需 User 扩展 + 端点 + 前端切换 UI |

### 批次三：高难度·依赖用户基数或整体架构

| 项 | 难度 | 改动面 |
|---|---|---|
| G5 积分抽奖/扭蛋 | 中高 | 奖池表 + 概率引擎（公示） + 防重幂等 × 前端动画；奖品须全平台内权益 |
| G9 个人月度赚分榜 + G10 赛季重置 | 中高 | 月榜查询（复用商家榜框架）+ 月度结算 Job + 赛季称号；规模需用户基数 |
| Admin 月度仪表盘 | 中 | 发放/燃烧/托管三条曲线按 grantType 聚合 + 月度仪表盘页；运营调价依据 |
| ExpireAt 过期策略 | 待决策 | 无 lot 明细只能整批时间窗过期（v2.1.0 第 12 章约束），启用前先定方案（直接时间窗 vs 先补 lot） |

**建议顺序**：批次一（本轮随新功能顺带）→ 批次二（独立专项）→ 批次三（DAU 起量 + 运营期）。G6 永久挂起不做。
