## 一、工会等级（复用 MerchantGrade，零新列）

定案：**不另设 GuildLevel 字段**——既有 `MerchantGrade`（Standard/Premium/Verified）本就是"商家等级"，
扩展 `Gold=4` 后四档语义与工会等级一一对应，避免两把梯子的双轨混乱：

| Lv | 枚举 | 达成条件（阈值全部走 SystemConfig，Admin 可调） |
|---|---|---|
| Lv1 入驻 | Standard=1 | Active 即得 |
| Lv2 认证 | Verified=3 | 证照审核通过 |
| Lv3 活跃供给 | Premium=2 | 认证 + 在售 ≥ `Business.GuildPremiumOnSaleMin`(5) |
| Lv4 金牌 | Gold=4 | 认证 + 在售 ≥ `Business.GuildGoldOnSaleMin`(10) + 金库累计 ≥ `Business.GuildGoldTreasuryMin`(500) |

**关键实现决策**
1. **枚举数值保留历史映射**（Standard=1/Premium=2/Verified=3/Gold=4），推进路径 1→3→2→4 与数值大小无关；
   一切等级比较必须经 `GuildBuffs.Rank()`（数值→序数 1-4），域内旧 `Grade < Verified` 比较已清除
   （Verify 无条件落 Verified；Unverify 回落 Standard；ReleaseToPool 回落 Standard——数值比较此处恰好仍正确）。
2. 定级口径用**实时在售明细数**（`GetOnSaleByMerchantAsync().Count()`）而非 Merchant.ProductCount 冗余列——后者仅在部分聚合路径刷新，商家自助上下架不经过它。
3. `IMerchantGradeService.RecomputeAsync`：**先 flush 调用方待写实体的再计数**（否则读到旧 IsOnSale），独立提交、吞一切失败；
   触发点=入驻审批(Verify 内置)、上架/下架/审核通过商品 handler、挂礼结算（手动+Job 两处）、释放（域方法直接回落）。
4. 展示中文 `GetGradeDisplayName()`：入驻商家/认证商家/活跃供给/金牌商家；DTO 新增 `GradeDisplay`（API MerchantDto/BFF MerchantDetail/Taro merchant.ts 三链路透传）。

## 二、成员 buff（被动加成，取最高等级工会，无主工会）

定案兑现：一人多商家 = 业务多归属、**经济单归属**——buff 取全部在职 Active 商户中 Rank 最高的一家
（平级取最早加入，确定性口径），**无 IsPrimary 字段无设置 UI**。

目录（`GuildBuffs` 静态查表，承 6977 定案；全部先加成后受 PointGrantRule 日上限截顶）：

| 等级 | buff |
|---|---|
| Lv1 | 签到 +1；寻货应答免费 +1/日 |
| Lv2 | 纠错采纳 ×1.1；登录 +1；发布免费 +1/日 |
| Lv3 | 纠错 ×1.2；签到 +2；应答 +3/日；置顶卡 9 折 |
| Lv4 | 纠错 ×1.25；签到 +3；应答 +5/日；发布 +1/日；置顶卡 8 折 |

**接线点**：
- `PointsService.ApplyGuildBuffAsync`：GrantAsync 唯一入口内，仅 daily_login(+1) / correction_adopted(×) 触发最佳工会查询（其余类型零开销直返）；签到在 CheckinAsync 阶梯后叠加。
- 寻货额度：发布按成员最佳工会 +1(Lv2+)；应答按**被经营商户自身等级**加成（额度按商户计数，口径对齐）；`GET /api/sourcing/quota` 展示与 handler 同源。
- 置顶折扣：MallService.RedeemAsync 按购买者最佳工会打折（个人/金库两通道同享）。
- **红线不越**：全部为发放/额度/折扣的被动量，不存在金库→个人账户的任何转账路径。

## 三、福利可视化（帮派园地最小版）

- `GET /api/points/guild-buff` → `{guildId, guildName, grade, rank, labels[], nextHint}`：
  labels=当前等级生效清单，nextHint=升下一级条件一句话（散人 rank=0 显示"加入认证商家可享…"引导——
  散人无福利是**设计而非惩罚**，制造入会动力）。
- Taro 任务中心新增"工会福利"卡（Lv 称号+绿勾清单+升级提示）；"积分商城 即将上线"同步改为真实"去兑换"入口。
- 金库页头部等级徽章（Lv 紫标）；商户详情页"已认证"徽标升级为等级中文名（金牌琥珀/活跃紫/认证金）。
