## 一、两套货币总览

| | 个人积分 | 商家金 |
|---|---|---|
| 载体 | PointAccount（每人一账本） | MerchantPointAccount（每店一金库） |
| 谁能支配 | 本人 | 仅商户管理员 |
| 互转 | **无互转路径**（合规红线：防提现通道与农场刷金） | 同左 |
| 唯二交集 | ① 成员合格赚分按 10% 滴入在职店铺金库（trickle 上供）② 管理员可用个人积分按汇率代付商品置顶（个人消费，不入金库） | |

共同纪律：不可充值、不可提现、不可折现、不可转让给他人；唯一去向是平台内消费。

## 二、个人积分规则

### 2.1 获取（默认规则值，Admin 积分规则页可调）

| 场景 | 数额 | 上限/说明 |
|---|---|---|
| 每日签到 | +2/+3/+4/+5/+5 阶梯 | 连签逐日爬升第 5 天起封顶 +5；断签回 2 |
| 每日登录 | +1 | 当日首次 API 请求自动发 |
| 纠错被采纳 | +20/条 | 日上限 100；平台审核采纳后到账 |
| 每日三件套 | +30 | 同日完成签到+纠错被采纳+寻货应答各 ≥1 次 |
| 集体任务成员奖 | +20~+50/次 | 店铺达成成员类任务时全体在职成员发放（如周纠错 5 条 → 每人 +20） |
| 成就解锁甜头 | +5~+10 | 点亮勋章附发；勋章点为独立荣誉值不可消费 |
| 完善资料 | +50 | 一次性（按不变量防重，非按用户） |
| 首次上架商品 | +20 | 一次性 |
| 入驻审批通过 | +100 | 一次性（按信用代码防重） |
| 注册奖励 | +50 | 规则默认停用，短信验证网关落地后启用 |

### 2.2 加成与彩蛋

- **商家 buff**：成员从"等级最高的在职商家"获得被动加成（签到 +1~+3、登录 +1、纠错 ×1.1~×1.25、应答额度 +1~+5、置顶卡 9折/8折），加成在日上限截断前生效。
- **积分暴击**：主动赚分 10% 概率 ×2、2% 概率 ×5（服务端 RNG，仍受日上限约束；签到结果回传倍数供前端动画）。

### 2.3 消费口

| 场景 | 价格 | 说明 |
|---|---|---|
| 寻货发布超额 | 20/次 | 免费 3 次/日；硬上限 10 次/日积分买不到 |
| 寻货应答超额 | 20/次 | 免费 20 次/日；硬上限 50 次/日 |
| 寻货置顶卡 | 60/160 | 24h/72h，个人积分原价 |
| 商城权益 | 见标价 | 权益包/礼品兑换等 |
| 商品置顶代付 | 标价 ×2 | 管理员个人通道按汇率折算（金库通道原价） |

### 2.4 边界

- 日切按东八区零点（BusinessClock，偏移可配）；全链路 UTC 存储。
- 当前不过期；过期策略（ExpireAt）预留未启用。

## 三、商家金规则

### 3.1 获取（三条入账通道）

| 场景 | 数额 | 说明 |
|---|---|---|
| 成员上供 trickle | 合格赚分 ×10% | 仅审核/交易类（纠错采纳、任务奖等）；签到登录注册等被动分排除；整除向下取整、余数给等级最高店铺；单店日上限 50、月上限 1000 |
| 挂礼成交结算 | 货款全额 | 买家确认收货（或发货 7 天自动确认）后结算入金库；争议未结算前为托管态 |
| 集体任务金库奖 | +100/次 | 金库类任务达成（如周新上架 5 款） |

### 3.2 消费（仅管理员，平台内）

| 场景 | 价格 | 说明 |
|---|---|---|
| 商品置顶卡 | 120/320 金 | 24h/72h，商家管理页默认金库支付；商家等级享 9折/8折 |
| 其他经营权益 | 陆续开放 | 金库不出平台 |

### 3.3 汇率（个人代付）

- 配置键 `Business.MerchantGoldPayRate`（默认 2）：管理员选个人积分通道代付商品置顶时按 `标价 × 汇率` 扣分。
- 设计意图：金库稀缺（只能干活攒）、积分易得（签到就有），汇率让经营支出自然流向金库；代付是个人消费，**不会**转成金库余额。

### 3.4 红线与生命周期

- 成员（非管理员）不能支取金库、看不到余额；多管理员共管，店铺须始终 ≥1 管理员。
- 店铺退出经营：挂礼释放回认领池、金库余额燃烧清零（`burn` 流水留痕），不折算给任何个人。
- 店铺等级（入驻/认证/活跃供给/金牌）由在售商品数与金库水位推导，等级决定成员 buff 档位——金库赚得越多，店铺等级越高，成员加成越好，形成正循环。
