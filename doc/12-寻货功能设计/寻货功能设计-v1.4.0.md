# 寻货功能设计 v1.4.0（发现页大厅化与大厅筛选）

> 版本：v1.4.0 | 日期：2026-09-30 | 上一版：v1.3.0
> 本版性质：增量版——发现页信息架构收敛（纯大厅 + 我的寻货/应答子 tab 分组）与大厅筛选（sort/brand/region）。

---

## 寻货需求置顶（v1.3.0 新增）

### 数据
- `SourcingDemand` 加 `PinnedUntil`（UTC 可空）+ `Pin(hours, nowUtc)`（有效期内续加、过期从当前起算，与商品置顶同语义）+ `IsPinned(nowUtc)`。
- 迁移 `AddDemandPin`：SourcingDemands.PinnedUntil 列 + MallItems.TargetKind 列 + 两档寻货置顶卡种子（24h=60 积分 / 72h=160 积分，个人积分定价，幂等键避让）。

### 经济规则
- 定价用**个人积分**（发布寻货是个人动作），不走商家金体系、无等级折扣（折扣锚定商家福利）。
- 兑换走商城 `redeem` 通用链：`item.TargetKind=2` 路由到需求校验（发布人本人 + 状态进行中），仅个人支付通道；金库通道对需求卡返回"寻货置顶仅支持个人积分支付"。

### 展示与入口
- 公开大厅：服务端有效置顶排前（`GetListAsync pinFirst`，过期旧值不插队），feed 输出 `isPinned/pinnedUntil`，卡片金色"置顶"角标。
- 我的寻货页：进行中需求显示"置顶/续置顶"按钮 → 选卡弹层（懒加载 targetKind=2 目录）→ 幂等兑换 → 刷新。
- 商城页：寻货置顶卡价格单位"积分"（商品置顶卡="商家金"），"去置顶"按对象类型分流两个入口页。

### 与积分体系 v2.10.0 的关系
本版同时把商品置顶卡改为**商家金定价 + 管理员默认金库支付 + 个人代付按 `Business.MerchantGoldPayRate`（默认 2）折算**，详见积分体系设计 v2.10.0。

## 发现页大厅化与大厅筛选（v1.4.0 新增）

### 三层信息架构定稿
- **发现页 = 纯公共大厅**：删除"进行中/我的寻货"双态 chips，只服务匿名可逛的进行中需求（onlyOpen feed），身份内容一律不混入广场。
- **我的寻货** = "我的"tab 独立页（pages/my/sourcing），页内「进行中｜已结束」子 tab 分组（默认进行中，计数展示）。
- **寻货应答** = 商家工作台独立页（pages/merchant/responses），页内「进行中｜已结束」子 tab 分组——进行中 = 应答待处理且需求仍开放（demandStatus 缺失按乐观归进行中），其余归已结束。
- 终态列表卫生由子 tab 承担（延续既有决策：不加"移入历史"操作、不做"标记成交"）。
- 三页各自独立、大屏与工作台分工（闲鱼/58 式"广场 + 个人列表 + 商家后台"）。

### 大厅筛选（search 结果页同款风格）
- **排序栏**：最新（默认 ↓）/ 最早（↑）发布时间切换，服务端 `sort=desc|asc`；**置顶恒排前不受排序影响**（付费曝光语义，pinFirst 规则在排序之上）。
- **筛选面板**（「筛选」按钮内联展开）：收货地区 = 34 省级单选网格 + 不限；期望品牌 = 品牌字典列表单选（BFF 新端点 `/mobile/brands` → API `/api/brands`，面板首开懒加载）；底部「重置 | 确定」确定式一次生效。
- **已选条件 chips**：`地区:xx ×`、`品牌:xx ×`，单项清除即重查（search 同款样式）。
- **匹配语义**：brand/region 与 keyword 均为**包含匹配**（发布时自由文本；Npgsql 翻译约束用 `ToLower()`），keyword AND brand AND region 正交叠加。
- **加载**：滚动无限分页保持——每页 20 条、触底追加、不设总量上限（分页本身即防大数据量加载成本；曾议"默认限量 100 条"最终未采纳）。
- 排序/筛选/搜索任一变化均重置回第一页重拉；"我发布"角标带 token 时生效（feed auth 改默认 true：有 token 即带、无 token 匿名可访）。

### feed 参数契约变更（v1.4.0）
- `GET /api/sourcing/demands` **删除 `mineOnly`**（"我的寻货"改走 `GET /my/demands` 独立端点，mineOnly 自 discover 页引入以来随大厅化收敛退役）；**新增 `brand` / `region` / `sort`**。
- 仓储 `GetListAsync` 同步：`mineOnlyUserId` 参数删除，新增 `brand` / `region` / `newestFirst`。
