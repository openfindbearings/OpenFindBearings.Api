### 1. 聚合根

#### 1.1 Bearing — 轴承聚合

轴承是系统的核心聚合根。每个轴承属于一个品牌和一个类型，可与多家商家关联。

| 属性组 | 字段 | 类型 |
|--------|------|------|
| 标识 | Id, CurrentCode(型号), OldNumber(曾用代号), CodeSource(代号来源) | Guid, string |
| 描述 | Description, StructureType, SizeSeries, IsStandard | string, bool |
| 尺寸 | Dimensions.InnerDiameter, OuterDiameter, Width | Dimensions 值对象 |
| 倒角 | ChamferRmin, ChamferRmax | decimal?（mm） |
| 性能 | PerformanceParams.DynamicLoad, StaticLoad, LimitingSpeed, LimitingSpeedGrease, LimitingSpeedOil | PerformanceParams 值对象（int?） |
| 其他 | Weight, PrecisionGrade, Material, SealType, CageType | decimal?, string |
| 图片 | Image3DUrl, Image2DUrl | string? |
| 来源 | DataSource.SourceType, DataSource.ImportedBy, DataSource.ImportedAt | DataSource 值对象 |
| 统计 | ViewCount | int |
| 追溯 | OriginCountry, Trademark | string? |
| 类别 | Category | BearingCategory 枚举（Domestic/Imported） |
| 数据验证 | IsVerified, LastVerifiedAt, VerifiedBy, DataRemark | bool, DateTime?, string?, string? |
| 计算 | FavoriteCount | int（计算属性） |
| 关联 | Brand(Brand), BearingType(BearingType) | 导航属性 |
| 集合 | Interchanges, MerchantBearings, FavoritedByUsers | 导航属性集合 |

**工厂方法：**
- `Bearing.Create(...)` — 创建标准轴承
- `Bearing.CreateNonStandard(...)` — 创建非标轴承

**业务方法：**
- `UpdateTechnicalSpecs(...)` — 更新技术参数
- `SetOrigin(...)` — 设置产地
- `IncrementViewCount()` — 增加查看次数

> 注：文档历史版本曾记载 `SearchCount` 和 `IncrementSearchCount()`，这两个成员实际存在于 `User` 聚合而非 `Bearing`。`Bearing` 仅有 `ViewCount`。

**唯一约束：** `(CurrentCode, BrandId)` 联合唯一索引

#### 1.2 Merchant — 商家聚合

| 属性组 | 字段 | 说明 |
|--------|------|------|
| 标识 | Id, Name, EnglishName, CompanyName | Guid, string |
| 联系 | ContactInfo(Phone, Mobile, Email, Address, ContactPerson, QQ) | ContactInfo 值对象 |
| 经营 | BusinessScope, Description, LogoUrl, Website, Type | string, MerchantType 枚举 |
| 工商 | UnifiedSocialCreditCode | string?（统一社会信用代码） |
| 认证 | IsVerified, VerifiedAt, VerifiedBy | bool + DateTime? + string? |
| 等级 | Grade | MerchantGrade 枚举 |
| 状态 | Status, SuspensionReason | MerchantStatus 枚举, string? |
| 统计 | ProductCount, FollowerCount, ViewCount | int |
| 数据追溯 | DataSource, LastVerifiedAt, VerifiedBy, IsVerified, DataRemark | DataSource?, DateTime?, string?, bool, string? |
| 集合 | Staff, MerchantBearings, FollowedByUsers, LicenseVerifications | 导航属性集合 |

**状态方法：**
- `Verify(string verifiedBy)` — 认证商家（仅标记认证等级，v1.3.0 起不再清除爬虫数据）
- `Unverify()` — 取消认证
- `Suspend(string reason)` — 暂停（需提供原因）
- `ActivateMerchant()` — 启用商家
- `Approve()` — **审核通过（Pending → Active，商户生效；v1.2.0 记载缺失的审核门，P3 补齐）**
- `MarkAsDraft()` — **标记为提名草稿（→ Draft，不可被C端检索/不被Sync合并；仅模式 B 提名使用）**
- `SubmitForApproval()` — **提交审核（Draft → Pending；提名被接受后由被提名人补全资料并提交）**
- `ReopenForClaim()` — **重新开放认领（曾被拒绝 Suspended 的爬虫商家再次被认领时清理拒绝标记恢复 Pending）**
- `Reject(string reason)` — **审核拒绝（Pending → Suspended + 原因，Deactivate）**
- `UpdateBasicInfo(companyName, unifiedSocialCreditCode, description, businessScope, logoUrl, website)` — 更新工商/简介信息
- `AddStaff(User user)` — 添加员工（无 role 参数）
- `RemoveStaff(User user)` — 移除员工
- `UpdateGrade(MerchantGrade grade)` — 更新等级

> 注：文档历史版本曾记载 `SortOrder` 字段，实际代码中不存在。`Suspend()` 实际需要 `reason` 参数。`AddStaff` 实际无 `role` 参数。

**状态枚举（MerchantStatus）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | Active | 正常（审核通过后生效） |
| 1 | Suspended | 已禁用/审核拒绝 |
| 2 | Pending | 待审核 |
| 3 | Draft | 草稿（提名他人为管理员时的未生效商户，不可被C端检索、不被Sync合并） |

#### 1.3 User — 用户聚合

与 Identity 服务的 OidcUser 通过 `AuthUserId` 桥接。

| 属性组 | 字段 | 说明 |
|--------|------|------|
| 标识 | Id, AuthUserId | Guid, Guid |
| 基本 | Nickname, Avatar, Phone, Email | string? |
| 等级 | Level, SubscriptionExpiry | UserLevel 枚举(Free/Premium/Enterprise), DateTime? |
| 注册 | RegistrationSource, RegisterIp, RegisteredAt | RegistrationSource 枚举, string?, DateTime? |
| 画像 | Occupation, CompanyName, Industry | UserOccupation?, string?, string? |
| 统计 | SearchCount, QueryCount, FirstSearchAt, LastSearchAt, LastActiveAt, LastLoginAt | int, int, DateTime?, DateTime?, DateTime?, DateTime? |
| 游客 | IsGuest, GuestSessionId, IsMerged, MergedToUserId | bool, string?, bool, Guid? |
| 商户 | MerchantId | Guid?（v1.3.0 标记废弃，仅兼容存量；成员关系以 MerchantMember 为准） |
| 集合 | Roles, FavoriteBearings, FollowedMerchants, BearingHistory, MerchantHistory, BehaviorLogs | 导航属性集合 |

**业务方法：**
- `RecordLogin()` — 记录登录
- `RecordSearch()` — 记录搜索
- `RecordQuery()` — 记录查询
- `UpdateLastActive()` — 更新最后活跃时间
- `UpdateProfile(...)` — 更新资料
- `UpgradeToPremium(DateTime expiry)` — 升级为付费用户
- `UpgradeToEnterprise(DateTime expiry)` — 升级为企业用户
- `DowngradeToFree()` — 降级为免费用户
- `MarkAsMerged(Guid targetUserId)` — 标记已合并
- `Enable()` / `Disable()` — 启用/禁用
- `AddRole(Guid roleId)` / `RemoveRole(Guid roleId)` — 角色管理
- `RecordBearingView(Guid bearingId)` — 记录轴承浏览
- `RecordMerchantView(Guid merchantId)` — 记录商家浏览
- `ClearHistory()` — 清除浏览历史
- `AssignToMerchant(Guid merchantId)` — 关联到商户（v1.3.0 起为兼容方法；新逻辑走 MerchantMember）

> 注：文档历史版本曾记载 `UserType`、`MembershipLevel`(Normal/VIP/Admin)、`MigrateGuestData(...)` 方法，实际代码中不存在。用户等级使用 `Level`(UserLevel 枚举：Free/Premium/Enterprise)。

#### 1.4 用户类型说明

| 类型 | 说明 | 商户关联 |
|------|------|----------|
| Guest | 未登录游客 | 无 |
| Normal | 普通注册用户 | 无 |
| MerchantStaff | 商户员工 | 属于至少一个商户（MerchantMember Role=MerchantStaff），可管理该商户库存 |
| MerchantAdmin | 商户管理员 | 属于至少一个商户（MerchantMember Role=MerchantAdmin），可管理该商户成员+库存 |

> v1.3.0 说明：商户域角色（MerchantStaff/MerchantAdmin）判定的唯一事实源是 **MerchantMember 成员表**（按 (用户, 商户) 维度），不再依赖 JWT role claim 或 User.MerchantId 单值列。一人可同时属于多个商户、在每个商户有不同角色。

#### 2.1 MerchantMember（v1.3.0 新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| UserId | Guid | 业务用户 Id |
| MerchantId | Guid | 商户 Id |
| Role | string | MerchantAdmin / MerchantStaff |
| Status | MerchantMemberStatus | Active / Removed / Suspended |
| InvitedBy | Guid? | 邀请人/入驻申请人 |
| JoinedAt | DateTime | 加入时间（UTC） |
| RemovedAt | DateTime? | 移除时间（UTC） |
| 唯一约束 | — | (UserId, MerchantId) 唯一 |

**常量：** `RoleMerchantAdmin="MerchantAdmin"`、`RoleMerchantStaff="MerchantStaff"`

**业务方法：**
- `Rejoin(role?, invitedBy?)` — 重新入伙（复用 Removed 行，不新增第二行）
- `ChangeRole(role)` — 变更角色（需合法角色值）
- `Remove()` — 移除成员（软移除，保留审计信息）
- `Suspend()` — 停用（保留关系但失去操作权限，可恢复）
- `Reactivate()` — 恢复被停用成员

**成员状态枚举（MerchantMemberStatus）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | Active | 在职（当前属于该商户） |
| 1 | Removed | 已移除（历史成员，可被重新邀请复用） |
| 2 | Suspended | 已停用（保留成员关系但无操作权限，可恢复） |

#### 2.2 StaffInvitation（v1.3.0 扩展）

| 字段 | 类型 | 说明 |
|------|------|------|
| MerchantId | Guid | 商户 Id |
| Email / Phone | string? | 受邀人联系方式（二选一） |
| Role | string? | 邀请角色（Admin/Staff） |
| InvitationCode | string | 邀请码 |
| OperatorId | Guid | 发起人（员工邀请=管理员；提名=发起人） |
| Type | InvitationType | Staff（员工邀请）/ Nomination（提名他人为管理员） |
| Status | InvitationStatus | Pending / Accepted / Declined / Expired / Revoked |
| InitiatorJoins | bool | 提名时发起人是否默认入伙为员工（默认 true） |
| IsCompleted / CompletedSub / CompletedAt | — | 完成标记（记录接受者的 AuthUserId 与时间） |

**业务方法：** `Complete(sub)` / `Decline()` / `Revoke()` / `MarkExpired()` / `IsExpired()`（7 天有效期）

**邀请类型枚举（InvitationType）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | Staff | 员工邀请（管理员邀请员工加入已生效商户） |
| 1 | Nomination | 提名（发起人提名他人为管理员，商户尚在 Draft 阶段） |

**邀请状态枚举（InvitationStatus）：**

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | Pending | 待处理 |
| 1 | Accepted | 已接受 |
| 2 | Declined | 已拒绝 |
| 3 | Expired | 已过期 |
| 4 | Revoked | 已撤销 |

#### 2.3 MerchantBearing 关键行为

- `Create(merchantId, bearingId, price?, stock?)` — 创建关联（默认在售，无需审核）
- `TakeOffShelf()` — 下架
- `PutOnShelf()` — 重新上架
- `SubmitForApproval()` — 提交审核
- `Approve()` — 审核通过
- `Reject(comment)` — 审核拒绝
- `UpdateMarketInfo(price, stock, minOrder, remarks)` — 更新市场信息
- `SetPrice(description, numeric?, visibility?)` — 设置价格
- `DataSourceType` — 枚举（Crawler / Manual），区分爬虫和商户自管数据

### 4. 基类

**BaseEntity** — 提供 `Id(Guid)`, `CreatedAt`, `UpdatedAt`, `IsActive`，以及 `AddDomainEvent()` 领域事件支持。

**ValueObject** — 基于组件值的相等性比较，不可变模式。
