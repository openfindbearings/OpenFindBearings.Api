### 1. 聚合根

#### 1.1 Bearing — 轴承聚合

轴承是系统的核心聚合根。每个轴承属于一个品牌和一个类型，可与多家商家关联。

| 属性组 | 字段 | 类型 |
|--------|------|------|
| 标识 | Id, CurrentCode(型号), OldNumber(曾用代号), CodeSource(代号来源) | Guid, string |
| 描述 | Description, StructureType, SizeSeries, IsStandard | string, bool |
| 尺寸 | Dimensions.InnerDiameter, OuterDiameter, Width | Dimensions 值对象 |
| 性能 | PerformanceParams.DynamicLoad, StaticLoad, LimitingSpeed, LimitingSpeedGrease, LimitingSpeedOil | PerformanceParams 值对象（int?） |
| 其他 | Weight, PrecisionGrade, Material, SealType, CageType | decimal?, string |
| 图片 | Image3DUrl, Image2DUrl | string? |
| 来源 | DataSource.SourceType, DataSource.SourceSite | DataSource 值对象 |
| 统计 | ViewCount, SearchCount | int |
| 追溯 | OriginCountry, Trademark, Category | string? |
| 关联 | Brand(Brand), BearingType(BearingType) | 导航属性 |
| 集合 | Interchanges, MerchantBearings, FavoritedByUsers | 导航属性集合 |

**工厂方法：**
- `Bearing.Create(...)` — 创建标准轴承
- `Bearing.CreateNonStandard(...)` — 创建非标轴承

**业务方法：**
- `UpdateTechnicalSpecs(...)` — 更新技术参数
- `SetOrigin(...)` — 设置产地
- `IncrementViewCount()` — 增加查看次数
- `IncrementSearchCount()` — 增加搜索次数

**唯一约束：** `(CurrentCode, BrandId)` 联合唯一索引

#### 1.2 Merchant — 商家聚合

| 属性组 | 字段 | 说明 |
|--------|------|------|
| 标识 | Id, Name, EnglishName, CompanyName | Guid, string |
| 联系 | ContactInfo(Phone, Mobile, Email, Address, ContactPerson) | ContactInfo 值对象（含 Phone + Mobile 双字段） |
| 经营 | BusinessScope, Description, LogoUrl, Type | string |
| 认证 | IsVerified, VerifiedAt, VerifiedBy | bool + DateTime? + string? |
| 等级 | Grade, SortOrder | enum, int |
| 集合 | Staff, MerchantBearings | 导航属性集合 |

**状态方法：**
- `Verify(string verifiedBy)` — 认证商家（记录审核人）
- `Unverify()` — 取消认证
- `Suspend()` — 暂停
- `AddStaff(User user, string role = "Staff")` — 添加员工
- `RemoveStaff(User user)` — 移除员工
- `UpdateGrade(MerchantGrade grade)` — 更新等级

#### 1.3 User — 用户聚合

与 Identity 服务的 OidcUser 通过 `AuthUserId` 桥接。

| 属性 | 说明 |
|------|------|
| AuthUserId | Identity 服务的用户 GUID |
| Nickname, Avatar, UserType | 业务层用户信息 |
| MembershipLevel | Normal / VIP / Admin |
| 集合 | Roles, FavoriteBearings, FollowedMerchants, BearingHistory, MerchantHistory |

**特别方法：**
- `AssignToMerchant(Guid merchantId, string role = "Staff")` — 关联到商户
- `RemoveFromMerchant()` — 解除商户关联
- `MigrateGuestData(...)` — 游客数据自动迁移

#### 1.4 用户类型说明

| 类型 | 说明 | 商户关联 |
|------|------|----------|
| Guest | 未登录游客 | 无 |
| Normal | 普通注册用户 | 无 |
| MerchantStaff | 商户员工 | 关联一个 Merchant，可管理库存 |
| MerchantAdmin | 商户管理员 | 关联一个 Merchant，可管理员工+库存 |

### 2. 实体

| 实体 | 表名 | 关键字段 | 说明 |
|------|------|------|------|
| Brand | brands | Code, Name, Level, Country, LogoUrl | 品牌字典（已删除 Website/Description/SortOrder） |
| BearingType | bearing_types | Code, Name, Description | 轴承类型字典（已删除 SortOrder） |
| BearingInterchange | bearing_interchanges | SourceBearingId, TargetBearingId, InterchangeType, Confidence, IsBidirectional | 替代品关系 |
| MerchantBearing | merchant_bearings | MerchantId, BearingId, PriceDescription, StockDescription, MinOrderDescription, Remarks, PriceVisibility, NumericPrice, IsOnSale, IsPendingApproval, IsFeatured, ViewCount, DataSourceType | 商家-轴承关联 |
| CorrectionRequest | correction_requests | BearingId/MerchantId, Type, Description, Status | 纠错请求 |
| AuditLog | audit_logs | UserId, Action, ResourceType, ResourceId, Details | 管理员操作日志 |
| ApiCallLog | api_call_logs | Endpoint, Method, StatusCode, Duration, UserId, IpAddress | API 调用日志 |
| SystemConfig | system_configs | Key, Value(JSON) | 系统配置键值存储 |

**MerchantBearing 关键行为：**
- `Create(merchantId, bearingId, price?, stock?)` — 创建关联（默认在售，无需审核）
- `TakeOffShelf()` — 下架
- `PutOnShelf()` — 重新上架
- `SubmitForApproval()` — 提交审核
- `Approve()` — 审核通过
- `Reject(comment)` — 审核拒绝
- `UpdateMarketInfo(price, stock, minOrder, remarks)` — 更新市场信息
- `SetPrice(description, numeric?, visibility?)` — 设置价格
- `DataSourceType` — 枚举（Crawler / Manual），区分爬虫和商户自管数据

### 3. 值对象

| 值对象 | 属性 | 说明 |
|--------|------|------|
| Dimensions | InnerDiameter, OuterDiameter, Width | 均为 decimal?，单位 mm |
| PerformanceParams | DynamicLoad, StaticLoad, LimitingSpeed, LimitingSpeedGrease, LimitingSpeedOil | 载荷单位 kN，转速单位 rpm（int?）|
| DataSource | SourceType(枚举), SourceSite(string?), SourceRecordId(string?) | Manual/Crawler/FileImport/Api/SeedData |
| ContactInfo | ContactPerson, Phone, Mobile, Email, Address | EF Core OwnsOne 映射 |

### 4. 基类

**BaseEntity** — 提供 `Id(Guid)`, `CreatedAt`, `UpdatedAt`, `IsActive`，以及 `AddDomainEvent()` 领域事件支持。

**ValueObject** — 基于组件值的相等性比较，不可变模式。
