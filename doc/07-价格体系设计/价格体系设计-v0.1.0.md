## 一、价格数据模型

### 1.1 实体字段

`MerchantBearing` 实体已包含 4 个价格相关字段：

| 字段 | 类型 | 含义 |
|------|------|------|
| `PriceDescription` | `string?` | 价格描述文本（"¥55-60"、"电议"、"面议"） |
| `NumericPrice` | `decimal?` | 数值化价格（用于排序与价格区间筛选） |
| `PriceVisibility` | `PriceVisibility`（Public / LoginRequired） | 可见性枚举 |
| `IsNegotiable` | 计算属性 | 文本包含"电议"或"面议"时为 true |

DTO `MerchantBearingDto` 额外暴露 `IsPriceVisible`（按 PriceVisibility + 当前用户登录状态计算）。

### 1.2 参考价（待设计）

`Bearing` 实体待新增 `ReferencePrice` 字段（`decimal?`），用于"无在售商家时的兜底价格"。详见独立讨论稿《参考价计算机制设计 v0.1.0》。

## 二、价格相关 SystemConfig 配置项

3 个价格配置项当前定义于 `SystemConfigs` 表的 `Price` 分组：

| 配置键 | 默认值 | 类型 | 作用 | 当前消费方 |
|--------|--------|------|------|------------|
| `Price.DefaultVisibility` | `LoginRequired` | string | 新建商家-轴承关联时若调用方未指定可见性，按此值设置 | ❌ 当前硬编码默认 `Public` |
| `Price.ShowNegotiableLabel` | `true` | bool | 商品价格为"电议/面议"时，前端是否显示"议价"标签 | ❌ 端点已暴露但前端未消费 |
| `Price.NumericForSorting` | `true` | bool | 是否允许按 `NumericPrice` 排序 | ❌ 排序逻辑不读此开关 |
| `Price.ExtractPattern` | `¥(\d+(?:\.\d+)?)` | string | 从价格文本提取数值的正则 | ❌ 解析逻辑使用硬编码 |

**现状：** 4 个配置项虽写入数据库，但无任何代码根据这些值改变行为。

## 三、价格配置项消费方案

### 3.1 `Price.DefaultVisibility` 消费

**消费点 1：** `CreateMerchantBearingCommandHandler`（Admin/商家创建在售商品）

```csharp
// 创建前：若未传 visibility，从 SystemConfig 读取默认值
var defaultVisibility = await _configRepo.GetValueAsync(
    "Price.DefaultVisibility", "Public");
var visibility = request.Visibility
    ?? Enum.Parse<PriceVisibility>(defaultVisibility);
```

**消费点 2：** `BatchCreateMerchantBearingsCommandHandler`（Excel 批量导入）

`dto.Visibility` 为 null 时同样读此配置。

**前端行为：** Admin 创建/导入商品时，UI 复选框"价格对所有人可见"勾选状态按此配置的默认值初始化。

### 3.2 `Price.ShowNegotiableLabel` 消费

**消费点：** `MerchantBearingDto` 增加 `ShowNegotiableLabel` 计算属性，按 `IsNegotiable && config` 计算。

**API 返回：** `MerchantBearingDto.ShowNegotiableLabel`（bool）随每次响应下发，前端无需单独调配置接口。

**前端行为：** Admin/MAUI 在"电议/面议"价格后显示 "[议价]" 角标；开关关闭时仅显示"电议"原文本。

### 3.3 `Price.NumericForSorting` 消费

**消费点：** `SearchMerchantBearingsQueryHandler` 排序逻辑

```csharp
var useNumeric = await _configRepo.GetValueAsync(
    "Price.NumericForSorting", true);
merchantBearings = request.SortBy switch
{
    "price" when useNumeric
        => request.SortOrder == "desc"
            ? merchantBearings.OrderByDescending(mb => mb.NumericPrice)
            : merchantBearings.OrderBy(mb => mb.NumericPrice),
    "price" => merchantBearings.OrderBy(mb => mb.Id), // 降级排序
    ...
};
```

**前端行为：** Admin 在售商品弹窗"按价格排序"按钮在配置关闭时禁用并提示"价格排序已关闭"。

### 3.4 `Price.ExtractPattern` 消费

**消费点：** `BatchCreateMerchantBearingsCommandHandler` 解析 `dto.Price`

```csharp
var pattern = await _configRepo.GetValueAsync(
    "Price.ExtractPattern", @"¥(\d+(?:\.\d+)?)");
var match = Regex.Match(priceText, pattern);
var numericPrice = match.Success ? decimal.Parse(match.Groups[1].Value) : null;
```

**前端行为：** 无直接交互；此配置仅在 L 阶段批量导入时生效。

## 四、缓存策略

价格配置项读取频率高（同一次搜索可能读 3 次），但变更频率极低。引入进程内缓存：

- 5 分钟 TTL（与 `IReliabilityConfigProvider` 一致）
- 缓存键 = 配置键
- 写入：Admin 通过 `PUT /api/admin/config/{key}` 修改后，发布 `ConfigChangedEvent`（预留，本期不实现跨进程失效，依赖 TTL 自然过期）

## 五、价格展示规范

### 5.1 Admin 端

**系统配置页（/Config/Index）：** 4 个价格配置项作为独立卡片"价格显示"，提供实时编辑能力。

**在售商品弹窗：** 价格列根据 `IsNegotiable && ShowNegotiableLabel` 决定是否加 "[议价]" 角标；按价格排序受 `NumericForSorting` 开关控制。

**创建/导入商品弹窗：** "价格可见性"下拉框默认选项 = `Price.DefaultVisibility` 配置值。

### 5.2 MAUI 端

**询价页（首页/查询）：** 轴承卡片增加"最低价 ¥XX 起"行，未登录显示"登录查看价格"。

**轴承详情页（待新建）：** 价格专区展示：
- 参考价（基于同型号同品牌商家报价均值）
- 在售商家列表：商家名 / 价格描述 / [议价] 角标 / 库存 / 起订量

**商家详情页（待新建）：** 该商家在售商品列表，含价格描述与[议价]角标。

### 5.3 API 响应规范

`MerchantBearingDto` 价格字段（无论配置如何，**始终返回所有字段**）：

| 字段 | 始终返回 | 说明 |
|------|----------|------|
| `PriceDescription` | ✅ | 原文本 |
| `NumericPrice` | ✅ | 数值（可能为 null） |
| `PriceVisibility` | ✅ | 枚举值 |
| `IsPriceVisible` | ✅ | 计算后（按 PriceVisibility + 用户登录状态） |
| `IsNegotiable` | ✅ | 计算后（文本含"电议/面议"） |
| `ShowNegotiableLabel` | ✅ | 计算后（IsNegotiable && Price.ShowNegotiableLabel） |

可见性由前端按 `IsPriceVisible` 决定是否显示具体数值，不在 DTO 上做条件省略（保持 API 稳定）。

## 六、实施步骤

按依赖关系分 3 步：

1. **Admin 端先行消费**（最小可用）  
   - `MerchantBearingDto` 增加 `ShowNegotiableLabel` 字段
   - `SearchMerchantBearingsQueryHandler` 读 `Price.NumericForSorting`
   - `BatchCreateMerchantBearingsCommandHandler` 读 `Price.DefaultVisibility` + `Price.ExtractPattern`
   - Admin "在售商品"弹窗消费 `ShowNegotiableLabel` + `NumericForSorting`

2. **后端价格配置缓存层**  
   - 引入 `IPriceConfigProvider`（5 分钟缓存）
   - 替换硬编码默认

3. **MAUI 价格展示**  
   - 询价页加价格行
   - 新建轴承详情页
   - 新建商家详情页
   - 参考价计算（详见独立文档）
